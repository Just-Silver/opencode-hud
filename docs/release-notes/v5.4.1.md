> **Windows 用户：5.3.0 / 5.4.0 的一键更新会失败，请关闭 opencode 后重跑安装脚本**
>
> 这两个版本内置的更新器在 Windows 上会重命名整个插件目录，而 opencode 运行时宿主对插件源码目录持有文件监听句柄，重命名会返回 `EPERM`，更新随即报错。5.4.1 已修复这条路径，但旧版本无法自我修复。
>
> - Windows: `irm https://raw.githubusercontent.com/Just-Silver/opencode-hud/main/install.ps1 | iex`
> - macOS / Linux: `curl -fsSL https://raw.githubusercontent.com/Just-Silver/opencode-hud/main/install.sh | bash`
>
> 两者都必须先退出 opencode（安装脚本同样会重命名旧目录），装完再重新启动。Linux / macOS 用户，以及 5.2.x 及更早版本的 Windows 用户不受影响，可正常一键更新。
