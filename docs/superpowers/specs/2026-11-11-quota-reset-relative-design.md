# 额度重置提示：改为相对剩余时长

- 日期：2026-11-11
- 状态：**待批准**
- 落点：`shared/format.ts` 的 `fmtResetTime` / `fmtResetHint` / `fmtAge`；provider 与渲染器不改
- 规模：小改动（2 个函数 + 单测）

## 1. 背景

额度卡片里有两个并列的「时间」，含义不同但没有任何文字区分：

| 位置 | 含义 | 来源 |
| --- | --- | --- |
| 组头右端「刚刚」 | 上次成功查询距今多久（数据新鲜度） | `QuotaStatus.ageMs` → `fmtAge` |
| 行内 `↻ 04:31 / 周一 / 21:16` | 上游额度窗口**重置**的时刻 | provider 把 `resetsAt` 经 `fmtResetHint` 塞进 `hint` |

`fmtResetTime` 现按 `diff` 分档：`<24h → HH:MM`、`<7d → 周X`、否则 `MM-DD`。由此产生：

1. **跨天歧义**：23:50 时 5h 窗口在次日 04:31 重置，只显示 `04:31`，无法区分今天还是明天。
2. **粒度混用**：同一列同时出现 `HH:MM` / `周X` / `MM-DD`，量级不可比；周窗口刚重置时 diff≈7d 显示 `MM-DD`，一分钟后变成 `周X`。
3. **「刚刚」与代码注释矛盾**：`model/quota.ts` 的注释写「没有可说的状态 → undefined（不让『刚刷新过』这种常态占宽）」，实现却只要有 `ageMs` 就输出，且年龄最粗只到分钟。

## 2. 目标与非目标

目标：

- `↻` 统一为**相对剩余时长**，不再出现绝对时刻。
- 数据年龄 <1 分钟显示 `0m`，删除「刚刚」文案。

非目标（明确不做）：

- 不做「正在刷新」的即时反馈（用户已否决）。
- 不改刷新间隔 / 退避 / 心跳 / 通知时机。
- 不改 bars 的列宽策略、百分比配色、组头布局与 `收起`/`合计` 规则。
- 不新增契约字段：仍然只用 `QuotaItem.hint` 文本。
- 不回填历史 spec 里的旧记录。

## 3. 方案

| 方案 | 形态 | 取舍 |
| --- | --- | --- |
| **A 相对（已选）** | `↻ 4h12m` / `↻ 5d` / `↻ 20d` | 跨天歧义与粒度混用一次消除；失去「周几 / 几点」的日历坐标 |
| B 绝对 + 跨日标注 | `↻ 明天 04:31` | 保留日历感；hint 列 8 → 13 列压缩进度条，粒度混用仍在 |
| C 混合 | 24h 内相对，其余保持日历 | 折中；24h 边界仍跳变，粒度仍分层 |

选 A：这一列的用途就是「还有多久恢复」，相对时长直接回答，且宽度最稳。用户 2026-11-11 选定 A。

## 4. 格式规则

`fmtResetTime(iso, now)`：

| 剩余 | 输出 | 例 |
| --- | --- | --- |
| 缺失 / 非法 / `diff <= 0` | `undefined`（不显示，不变） | — |
| `< 60min` | `${m}m` | `12m` |
| `< 24h` | `${h}h` / `${h}h${m}m`（分钟为 0 时省略分钟） | `5h`、`4h12m` |
| `>= 24h` | `${d}d`（天向下取整） | `1d`、`5d`、`20d` |

- 全部向下取整：宁可少报，也不让「还剩 30 秒」显示成 `1m`。
- `fmtResetHint` 的 `↻ ` 前缀不变。
- `fmtAge(ms)`：`minutes < 1 → 0m`；`1m..59m`、`2.4h`、`3d` 等其余规则不变。

## 5. 影响面

- `shared/format.ts`：两个函数实现与注释（`fmtResetTime` 的分档说明、`fmtAge` 的「刚刚」）。
- `tests/shared.test.ts`：`fmtResetTime` / `fmtResetHint` / `fmtAge` 用例。
- 不改 provider、`model/quota.ts`、`renderers/bars.tsx`：`hint` 仍是自由文本。
- 宽度：hint 列常见 5–8 列（`↻ 4h12m` = 8），与现状持平；极端值 `↻ 23h59m` = 9 列，只影响当组的进度条 1 列。

## 6. 验收

- 23:50 时 5h 窗口显示 `↻ 4h09m` 一类相对值，不再出现裸时刻。
- 周窗口 `↻ 5d`、月窗口 `↻ 20d`。
- 刷新完成后组头立即是 `0m`，之后 `1m`、`2m`……不再出现「刚刚」。
- 已过期或无 `resetsAt` → 该行不渲染 `↻`。
- 单测覆盖：59s → `0m`、60s → `1m`、59m、1h、4h12m、23h59m、24h → `1d`、29d、过期 / 非法 → `undefined`。
